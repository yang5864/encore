# 추가 아이돌 캐릭터 이미지

여성 6명과 남성 6명을 추가 제작했습니다. 기존 여성 3명·남성 3명과 합치면 남녀 각 9명, 총 18명입니다.

각 캐릭터는 투명 배경 PNG 2장(눈 뜸·완전히 감음)이며, 머리 모양·실루엣·눈매·액세서리·의상을 다르게 설계했습니다. 첨부된 실사 사진은 스타일 참고용으로 사용했습니다.

- 미리보기: [preview.html](preview.html)
- 이미지: `characters/avatar-{6..17}/idle-open.png`, `idle-closed.png`
- 등록용 메타데이터: [manifest.json](manifest.json)
- 생성 방식: built-in image_gen
- 전체 최종 프롬프트·입력 참조·원본 경로: [GENERATION.jsonl](GENERATION.jsonl), `production/*.json`

## 연결 범위

이번 결과는 이미지 제작본입니다. 게임 캐릭터 선택 목록이나 실행용 카탈로그는 수정하지 않았습니다. 새 12명의 이벤트별 의상·동작은 포함하지 않으며, 기본 이미지와 깜빡임 프레임만 제작했습니다. ID 6–11은 여성, 12–17은 남성입니다. 기존의 ID 0–2 여성, 3–5 남성 구분을 확장할 때 이 매핑을 사용해야 합니다.

검증: 24장 모두 RGBA 투명 배경, 캔버스 경계 잘림 없음, 미리보기 이미지 24개 정상 로드.
