# Character frames

Built-in image_gen mode. One image call per character per frame, transparent_background=true. Generated originals copied without resizing, cropping, compositing or other pixel edits. No source code modified.

## Frames

Playback order by animation: idle-01 → idle-02; sing-01 → sing-02; dance-01 → dance-02. Each file contains one full character pose, never a sprite sheet. All idle-01 references were generated from public/sprites.webp and viewed before being used as edit references. Avatar-0 and avatar-1 later frames reference that avatar's idle-01 PNG.

## Shared prompt

Use case: identity-preserve game character animation frame. Create ONE standalone transparent PNG, square canvas, ONE full-body cute Korean chibi pixel-art character only. Preserve the exact identity, face, hairstyle, hair accessory and outfit of the designated reference character. Crisp native pixel clusters, warm cute shading, no blur. The character is centered at x50%, feet baseline at y85%, whole body including hair arms and shoes fully visible, at least 20% blank margin left and right. Same scale, framing and camera for every frame. True transparent background. No background, no ground shadow, no border, no text, no other characters, no duplicates, no motion trails, no sprite sheet.
