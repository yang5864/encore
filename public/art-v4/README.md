## 파일 구성

- 캐릭터: `characters/avatar-{0..5}/{event}/01.png`, `02.png`
- 배경: 기존 `../art-v3/backgrounds/{event}.png` (인물 없는 32종)
- 생성 계획과 의상·동작 원문: `PLAN.json`
- 실제 생성 요청과 참조 파일: `PROMPTS-A.jsonl`, `PROMPTS-B.jsonl`, `PROMPTS-C.jsonl`, `PROMPTS-ROOT.jsonl`
- 최종 파일 목록·크기·투명 영역·발 위치: `manifest.json`
- 검증 결과: `VALIDATION.md`

## 배경 위에서 사용하는 방법

이벤트 키로 같은 이름의 배경을 찾고, 사용자가 고른 avatar 폴더의 01/02를 번갈아 표시할 수 있습니다. 각 PNG의 투명 여백을 유지하고 발 위치를 기준으로 배치하세요. 실제 캔버스 크기와 발 위치는 manifest.json에 기록합니다. 이미지마다 생성 과정의 미세한 비율 차이가 있어 발 위치를 함께 참고하는 것이 좋습니다.

이 패키지는 이미지와 이미지 설명 자료만 포함합니다. 앱 컴포넌트·이벤트 조건·게임 수치·애니메이션 실행 로직은 수정하지 않았고, 배포도 실행하지 않았습니다. 기존 art-v3와 기존 런타임 이미지는 그대로 보존했습니다.
