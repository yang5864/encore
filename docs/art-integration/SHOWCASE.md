# 메인 쇼케이스·깜빡임 조정

- 기본 대기: 4.2초 주기 중 3.864초 눈 뜸, 0.336초 완전 폐안. 이전 0.126초보다 길게 표시합니다.
- 메인 타임라인은 저장된 커리어의 캐릭터·달성 단계와 독립적으로 움직입니다.
- 캐릭터 0부터 연습생(댄스 연습) → 데뷔(무대 의상) → 음방 1위(트로피 첫 동작) → 대상(트로피 두 번째 동작) → 레전드(월드투어)를 2.6초 간격으로 표시합니다.
- 다섯 단계를 마친 뒤 다음 캐릭터의 연습생 단계로 돌아옵니다. 6종이 순환하고, 여섯 번째 다음에는 첫 캐릭터로 돌아옵니다.
- 기존에 만든 이미지 30종을 재사용했습니다. 단계가 바뀌면 이미지 로딩 상태도 초기화합니다.

검증: 테스트 48개와 타입 검사 통과. 새 컴포넌트·헬퍼·테스트의 ESLint 통과. 홈 페이지의 기존 로컬 저장소 로딩 effect에는 기존 set-state-in-effect 진단이 남아 있으며 이번 변경에서 다루지 않았습니다.

모바일 브라우저에서 저장 캐릭터가 5번이고 레전드 달성 상태인 경우에도 0번 연습생부터 시작하는 것을 확인했습니다. 여섯 캐릭터의 30단계와 첫 단계 복귀까지 31개 상태를 검증했고, 새 폐안 구간과 모션 감소 동작도 통과했습니다. 브라우저 오류와 HTTP 실패는 0건입니다. 상세 결과는 showcase-browser-results.json에 있습니다.

개발 서버가 이전 CSS를 제공해 기존 .next/dev 캐시는 .next/dev-ui-backup-*로 보존하고 새로 시작했습니다. 로컬 파일에 반영했으며 커밋·푸시·배포는 실행하지 않았습니다.
