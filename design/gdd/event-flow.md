# 이벤트 흐름

## Summary
시즌이 끝나면 이벤트를 최대 하나 고른다. 예약 → 상태 → 돌발 사건 → 숨은 이벤트 → 이야기 순서. 한 시즌에 플레이어가 내리는 결정은 계획 1개 + 이벤트 1개가 원칙이다.

## Overview
- 예약: 연습생 계약 만료, 고교 진학, 마지막 계약 기회, 파산, 재계약(7년), 포텐 캐스팅, 입대, 방출, 데뷔 평가 결과.
- 상태: 쇼케이스·음방 후속, 불화, 건강.
- 돌발 사건: 시즌당 17% + 인기/400 (최대 38%). 같은 사건 4시즌 쿨다운, 사건 다음 시즌은 조용.
- 이야기: 85% 확률로 조건 맞는 이야기 중 가중치 추첨. 커리어당 1회(반복 허용 사건만 재등장).
- 연말(하반기 끝, 데뷔 후): 연말 시상식.

## Detailed Design
- 연말 시상식은 빠질 수 없어 초청 확인 시트 없이 바로 시상식 화면으로 간다(초청 정보는 결과 메모).
- 시상식이 있었던 시즌에는 **예약 이벤트만** 이어진다(재계약·입대·파산). 돌발 사건과 이야기는 뽑지 않고, 연초 홍보 예산 선택은 다음 시즌으로 한 번 미룬다.
- 데뷔 시즌은 예외적으로 데뷔 제안 → 콘셉트 → 쇼케이스 → 데뷔 무대가 이어진다(마일스톤).
- 연말 시상: 신인상(데뷔 1년 안), 본상(연 1개), 대상. 상 이름은 시상식별 실제 부문명을 쓴다.

## Formulas
| 이름 | 식 | 범위 |
|---|---|---|
| 돌발 사건 확률 | 아이돌: clamp(0.17 + 인기/400 + (결속<30 ? 0.04 : 0), 0.12, 0.38). 그 외 0.06 | 0.06~0.38 |
| 이야기 확률 | 0.85 (다른 이벤트가 없을 때) | — |

예시: 인기 72, 결속 50 아이돌 → 0.17 + 0.18 = 0.35(35%). 결속 25면 0.38(상한).

## Edge Cases
- 예전 저장본에 남은 초청 시트(`awards-invite`)는 그대로 열리고 참석 처리된다.
- 열애설·사생팬은 커리어당 최대 2회. 논란 뒤 2시즌 자숙.
- 계약 직후 2시즌은 다른 소속사 제안이 오지 않는다.

## Dependencies
- 모든 시스템이 이벤트 효과를 받는다. 시상식은 컴백·차트 지표의 연간 성적을 읽는다.

## Acceptance Criteria
- Given 96명 자동 플레이, When 아이돌 시즌의 이벤트 수를 세면, Then 평균 1.1 이하이고 2개 이상인 시즌은 10% 이하 (`scripts/probe-review.ts`).
- Given 연말 시상식이 끝나면, Then 다음 시트는 없거나 예산·재계약·입대 중 하나다 (`tests/qa-rules.test.ts`).
- Given 아이돌 시즌, When 돌발 사건 비율을 재면, Then 18~30%.
