# 컴백·차트 지표

## Summary
한 번의 컴백에서 활동 점수 5개(음원·음반·방송·소셜·투표)를 먼저 구하고, 그 점수를 실제 집계 비율대로 섞어 음악방송 6개 1위, 멜론 최고 순위, 빌보드 진입, 초동, 팬 유입, 화제성, 브랜드평판을 정한다.

## Overview
- 컴백 = 콘셉트 4종 × 타이틀 제작 3종(회사 A&R · 유명 프로듀서 · 자작곡) × 프로모션 4종(균형 · 음원 · 음반 · 해외).
- 결과는 서로 얽힌다. 음원 점수가 높으면 멜론과 인기가요에 강하고, 팬덤×결속이 높으면 음반과 더쇼에 강하다.

## Detailed Design
- 유명 프로듀서: 완성도 +10, 음원 점수 +3, 제작비 ×1.6. 차트 성적 빌드 — 인기·음방 1위는 가장 높고 정산은 가장 낮다.
- 자작곡: 프로듀싱 70+ 완성도 +6, 55~69 +3, 55 미만 −6. 제작비 ×0.7, 프로듀싱 +2.
- 프로모션: 음원 집중 음원 +6·음반 −4 / 음반 집중 음반 +10·초동 ×1.2·팬 유입 ×1.25·결속 +3 / 해외 집중 빌보드 +8.
- 라이벌 컴백(약 40% 시즌): 경쟁 바 +9. 방탄소년단이면 음방 +12 · 멜론 +5 추가.
- 데뷔 앨범은 음방 바 +10, 두 번째 앨범은 +5.
- 화제성(`buzz`)은 시즌 시작마다 ×0.55, 미디어 열기는 ×0.5로 식는다.

## Formulas
| 이름 | 식 | 범위 |
|---|---|---|
| 음원 점수 | 0.42 완성도 + 0.22 인기 + 0.20 화제성 + 0.16 팬덤×(0.6+0.4 결속) + 프로모션(음원 +6, 음반 −3) + 유명 프로듀서 +3 + (음원 예산−25)/5 + 0.6 기대감 | 0~100 |
| 음방 1위 확률 | 로지스틱((방송별 가중합 − 바 − 4)/5). 바 = 방송 기본(62~72) + 시대(2012+ 3, 2016+ 6) + 라이벌 9 + 신인 10/5 | 0.01~0.90 |
| 멜론 최고 순위 | edge = 음원 + 0.15 소셜 + 10×noise − (62 + 시대 + 라이벌 3); edge<0 차트 밖, 아니면 round(100·e^(−edge/8.5)) | 1~100 |
| 빌보드 진입 | 인기 70+ · 팬 150만+(시대 보정) 일 때 0.4 소셜 + 0.3 음원 + 0.3 투표 + 보정 ≥ 92 | 1~100 |
| 브랜드평판 지수 | 1위 지수 × (0.3 참여 + 0.3 미디어 + 0.15 소통 + 0.25 커뮤니티)^1.35 × (0.55+0.45 인기) × 1.25 × 흔들림(0.94~1.06) | 실측 스케일 |

예시: 음원 점수 80, 소셜 60, noise 0, 2020년(시대 +6), 라이벌 없음 → edge = 80 + 9 − 68 = 21 → 100·e^(−21/8.5) ≈ 8위.

## Edge Cases
- 같은 콘셉트 3번째부터 완성도 −4/회(최대 −12), 2번 이상 연속 뒤 바꾸면 차트 +5.
- 실패 앨범은 팬 10~18% 이탈, 바이럴은 화제성 +30.
- 인스타 개설 전에는 인스타 지표가 자라지 않는다.

## Dependencies
- 커리어 성장: 능력치·OVR → 완성도.
- 팬덤·팀 운영: 결속·케미·콘셉트 피로 → 점수와 완성도.
- 정산 경제: 제작비·예산·매출.

## Acceptance Criteria
- Given 전략 5종 × 24시드, When 데뷔 후 컴백을 반복, Then 어떤 전략도 인기·팬·음방 1위·정산 네 축 모두에서 다른 전략을 앞서지 않는다.
- Given 같은 콘셉트만 반복, When 26세에 비교, Then 인기·정산 모두 콘셉트 로테이션보다 낮다.
- Given 방탄소년단과 컴백이 겹치면, Then 같은 점수에서 음방 1위 확률이 라이벌 없음보다 낮다 (`tests/qa-rules.test.ts`).
